# DSA Practice

Daily Data Structures & Algorithms practice in Java.
**Target:** 1 Easy + 2 Medium per day.

## Structure

```
DSA-Practice/
├── daily/
│   └── YYYY-MM-DD/
│       ├── easy/       ← 1 easy problem
│       └── medium/     ← 2 medium problems
├── topics/             ← problems organized by topic
│   ├── arrays/
│   ├── strings/
│   ├── linked-lists/
│   ├── trees/
│   ├── graphs/
│   ├── dynamic-programming/
│   ├── binary-search/
│   ├── stack-queue/
│   └── hashing/
├── templates/          ← solution template
└── PROGRESS.md         ← daily log
```

## Daily Workflow

1. Copy `templates/Solution.java` into the day's folder
2. Rename it to the problem name (e.g., `TwoSum.java`)
3. Solve it, add time/space complexity in the header comment
4. Copy the file into the matching `topics/` folder too
5. Update `PROGRESS.md` with the day's entry
